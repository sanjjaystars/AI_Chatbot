# 🤖 AI Chatbot using Python

A command-line AI chatbot built using Python and the OpenAI API.  
This project demonstrates real-time AI interaction, conversation memory handling, and secure API integration using environment variables.

---

## 🚀 Features

- 💬 Real-time AI-generated responses
- 🧠 Maintains conversation history during session
- 🔐 Secure API key management using `.env`
- 🐍 Built with clean Python structure
- 📦 Virtual environment support (Kali/Linux safe)

---

## 🛠 Tech Stack

- Python 3
- OpenAI API
- python-dotenv
- Virtual Environment (venv)
